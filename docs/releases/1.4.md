# Shatranj 1.4 — Open Match

Draft release notes. Publish after stable Spectranext firmware acceptance.

Shatranj brings the same network chess game to ZX Spectrum Classic, Spectrum
Next, Spectranext, Windows, macOS and Linux. Version 1.4 adds MATCH on
Spectranext: find an opponent from the game, then play through the cartridge's
connection service.

## What's new

- **CREATE a game:** choose your name and colour and wait on Shatranj's own
  screen. The lobby shows your name followed by `(W)` or `(B)`.
- **JOIN an opponent:** choose from up to nine hosts with UP/DOWN and press
  ENTER or SPACE. BREAK returns to Setup. The cursor stays responsive while
  the list refreshes and preserves your selected host when entries move.
- **Clear connection feedback:** CONNECTING appears before pairing.
  Rejected or stale selections return the guest to Setup with CONNECTION
  FAILED, without automatically connecting to a different host.
- **Reliable exits:** intentional disconnects give the peer time to receive
  BYE before closing the MATCH tunnel; returning to Setup clears the picker
  footer completely.
- **Correct player names:** Spectrum move-list headers distinguish valid
  names such as `AD` and `A_X`.

## MATCH requirements

Both players need Spectranext with **firmware 1.2 or later** and different
public IP addresses. Select **LINK MATCH** in Setup, then CREATE on the host
and JOIN on the guest. MATCH handles discovery and pairing through the
firmware service; there is no IP address, forwarded port or MQTT room to
exchange.

DIRECT and MQTT remain available across all platforms. The desktop client,
Classic and Spectrum Next do not join the MATCH lobby; choose DIRECT or MQTT
on both sides for those games. Spectranext firmware 1.0/1.1 still runs the game
with those modes, and focusing LINK explains the 1.2 requirement.

A GitHub Release ZIP is not a mountable cartridge resource.

## Upgrading from 1.3

Settings, STJ1 saved games and recovery data keep their existing formats.
MATCH is an additional Spectranext link mode; DIRECT/MQTT interoperability
with 1.3 remains unchanged. Stockfish, statistics and recovery are still
available. With older supported cartridge firmware, a saved MATCH setup opens
as DIRECT so its connection settings can be completed.
If downgrading the game to 1.3, save a DIRECT or MQTT setup first: 1.3 does
not recognise a saved MATCH configuration.

See the [changelog](https://github.com/IgnacioMonge/shatranj/blob/main/CHANGELOG.md)
for the complete changes and the
[README](https://github.com/IgnacioMonge/shatranj#readme) for setup.
The published packages will be listed in `SHA256SUMS.txt`.
