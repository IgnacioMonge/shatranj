# Shatranj 1.4 — Open Match

Released 2026-10-21.

Shatranj brings the same network chess game to ZX Spectrum Classic, Spectrum
Next, Spectranext, Windows, macOS and Linux. Version 1.4 adds MATCH on
Spectranext: find an opponent from the game, then play through the cartridge's
connection service.

## What's new

- **Meet and play from your Spectrum.** MATCH adds a live opponent lobby to
  Spectranext. No IP addresses to exchange, router ports to open or MQTT room
  to agree on.
- **Host a game your way.** Choose CREATE, your player name and whether you
  play white or black. Other players see your name and colour in the lobby.
- **Join a waiting opponent.** Choose JOIN, browse the host list with UP/DOWN
  and press ENTER or SPACE on the player you want to challenge.
- **Keep the full game.** Chat, clocks, move history, takebacks, save/restore
  and statistics are available in MATCH. DIRECT and MQTT still connect all
  platforms, including opponents controlled by Stockfish in the Qt client.

![MATCH host selection in Shatranj 1.4 for Spectranext](https://raw.githubusercontent.com/IgnacioMonge/shatranj/v1.4/docs/screenshots/shatranj-1.4-spectranext-match-lobby.png)

## MATCH requirements

Both players need Spectranext with **firmware 1.2 or later** and different
public IP addresses. Select **LINK MATCH** in Setup, then CREATE on the host
and JOIN on the guest. MATCH handles discovery and pairing through the
firmware service; there is no IP address, forwarded port or MQTT room to
exchange.

DIRECT and MQTT remain available across all platforms. The desktop client,
Classic and Spectrum Next do not join the MATCH lobby; choose DIRECT or MQTT
on both sides for those games. Spectranext firmware 1.0/1.1 still runs the game
with those modes, and focusing LINK explains the 1.2 requirement.

Keep the Classic ZIP's `SHATRANJ.tap`, `SHATRANJ.OVL` and `SHATRANJ.DAT`
together. The Next ZIP contains the self-contained `SHATRANJ.nex`.
Classic and Next networking require a supported UART-to-ESP connection with
ESP-AT firmware; Classic also needs divMMC/esxDOS.

For Spectranext, select **Load Resource URL** in the cartridge menu:

- [Play directly from the web](https://ignaciomonge.github.io/shatranj/).
- [Install in local cartridge storage](https://ignaciomonge.github.io/shatranj/install/).

Both addresses serve 1.4. A GitHub Release ZIP is not a mountable cartridge
resource; enter one of these HTTPS addresses in the cartridge menu.

MATCH has been tested in FuseX and on a physical cartridge on the same LAN
with the documented test setup. A test between two different public networks
remains outstanding; for normal same-network play, use DIRECT.

## Upgrading from 1.3

Settings, STJ1 saved games and recovery data keep their existing formats.
MATCH is an additional Spectranext link mode; DIRECT/MQTT interoperability
with 1.3 remains unchanged. Stockfish, statistics and recovery are still
available. With older supported cartridge firmware, a saved MATCH setup opens
as DIRECT so its connection settings can be completed.
If downgrading the game to 1.3, save a DIRECT or MQTT setup first: 1.3 does
not recognise a saved MATCH configuration.
