Two ways to start

Dos formas de empezar

Connect the cartridge to Wi-Fi, open its menu and choose Load Resource URL. Your settings and saved games live in the cartridge's local storage either way, and both options share them.

Conecta el cartucho a la Wi-Fi, abre su menú y elige Load Resource URL. La configuración y las partidas guardadas viven en el almacenamiento local del cartucho en ambos casos, y las dos opciones las comparten.

Nothing to install Sin instalar nada

Play from the web

Juega desde la web

https://ignaciomonge.github.io/shatranj/
  1. Enter this address in Load Resource URL.
  2. Shatranj downloads and starts at once; nothing is copied to the cartridge.
  3. Each start fetches the published version, so you always play the latest release.
  1. Introduce esta dirección en Load Resource URL.
  2. Shatranj se descarga y arranca al momento; no se copia nada al cartucho.
  3. Cada arranque descarga la versión publicada, así que siempre juegas la última.
Works without the web Funciona sin la web

Install on the cartridge

Instálalo en el cartucho

https://ignaciomonge.github.io/shatranj/install/
  1. Enter this address in Load Resource URL.
  2. The guided installer copies Shatranj to local storage and launches it.
  3. From then on start SHATRANJ.ZX from local XFS. Load the address again to update.
  1. Introduce esta dirección en Load Resource URL.
  2. El instalador guiado copia Shatranj al almacenamiento local y lo inicia.
  3. En adelante, inicia SHATRANJ.ZX desde el XFS local. Vuelve a cargar la dirección para actualizar.
⚠ Both options need Spectranext firmware 1.0 or later. Older firmware shows FIRMWARE OUTDATED: SEE README; update the cartridge first. MATCH needs firmware 1.2 or later and players on different public IP addresses. Las dos opciones necesitan firmware de Spectranext 1.0 o posterior. Con un firmware anterior aparece FIRMWARE OUTDATED: SEE README; actualiza antes el cartucho. MATCH necesita firmware 1.2 o posterior y jugadores con distintas IP públicas.
